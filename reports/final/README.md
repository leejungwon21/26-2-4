## 3. 모델 성능 — v1 완료

[`models/results_v1.md`](models/results_v1.md): 319개 법정동 중 64개를 공통 test로 고정했다.
12개 국면×방식에서 기준선 2개와 Ridge·랜덤포레스트·CatBoost를 비교했다.
학습 내부 검증으로 12개 표 모두 CatBoost를 선택했고, 선택은 test 평가 뒤 바꾸지 않았다.
CatBoost의 test RMSE는 모든 표에서 자치구 평균보다 낮았으며, 짝지은 단지 부트스트랩
95% 구간에서도 개선 방향이었다. 일부 표의 test 최저 오차 모델은 랜덤포레스트 또는 Ridge였다.
모든 지표·구간·예측과 검증 내역은 `models/`에 있다. 구간은 고정된 모델에 조건부다.
