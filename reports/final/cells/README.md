## 계산 규칙

- 셀: 자치구·법정동·번지·단지명 × 1㎡ 반올림. 기존 파일럿과 같은 half-even 반올림이다.
- 창 방식 y: 시작/끝 창의 지수 보정 로그 ㎡당 가격 중앙값 차이에서 서울 변화를 뺀 값 ×100. 가중치는 양쪽 거래 수의 최솟값.
- 기울기 y: `100 × (ln 총거래가격 − ln 자체지수 main)`을 월순번에 회귀한 기울기 × 국면 길이. 거래 2건 이상, 간격 6개월 이상. 가중치는 `거래 수 × 간격(개월)`로 구체화했다.
- 연식: 국면 시작 월과 사용승인월의 차이. 사용승인일이 없으면 건축년도 7월을 사용한다.
- 역·학교: 저장된 계약일 특성을 복사하지 않고, 기존 시설 개통·폐교 이력과 좌표에서 **국면 시작 월 말일** 기준으로 다시 계산했다. 거리 단위는 직선거리 m.
- 층: 설정에 따라 창 방식은 시작 창 거래 중앙값, 기울기 방식은 확장 국면 내 거래 중앙값이다. 이는 사후 관측된 거래 구성 요약이며 엄격한 사전 예측용 특성은 아니다.
- 정적 특성: 현재값을 과거에 적용하는 기존 가정을 유지한다. 단지 안 값이 다르면 비결측 최빈값, 동률이면 문자열 정렬 첫 값을 사용한다. 좌표는 실제로 관측된 좌표 쌍의 최빈값을 사용한다.
- 결측: 원자료 결측을 임의 대체하지 않고 15개 특성별 `_missing` 열을 추가했다. 학습 시 대체는 학습 fold 안에서만 한다.
- 극단적인 y도 삭제하지 않았다. 파일럿의 `abs(y)<60` 필터는 확정 설정에 없어 적용하지 않는다. 기울기 추정치는 짧은 거래 간격의 추세를 전체 국면으로 늘려 큰 값이 나올 수 있다.

## 확장 통제 변수

- `토지거래허가구역_a`: 기존 국면 시작일 파일과 단지 키로 연결하고 날짜를 검증했다.
- `가격대`: a−12~a−4개월의 셀 중앙 총거래가격. 현재 시작 창과 겹치는 월은 사용하지 않는다. 9억 이하 / 9~15억 / 15억 초과. 거래가 없으면 결측.
- `회전율`: 시작 창 직전 12개월의 셀 거래 수 / 세대수. 관측 기간이 12개월에 못 미치면 결측으로 두고 `turnover_history_complete`에 기록한다.
- `직전국면_y`: 직전 국면의 창 방식 y. 끝 창을 현재 시작 창의 직전 월까지 잘라 다시 계산한다. 양쪽 창 거래가 없거나 이전 국면이 없으면 결측이다. 직전 국면 전체의 확정 y와 동일한 값은 아니다.

## 파일

- `{국면}_{window|slope}_v1.csv.xz`: 모델 입력 후보 12개 표. 식별자, y, 가중치, 기본 15개 특성, 결측 표시, 통제 변수와 검증용 열을 포함한다.
- `summary_v1.csv`: 단계별 셀 수 및 y 분포(평균·중앙값·1/99백분위·최솟값·최댓값). 분포 요약은 비가중이다.
- `excluded_trades_v1.csv`: 제외 거래ID와 이유. 원본은 수정하지 않았다.
- `excluded_cells_v1.csv.xz`: 목표값을 만들지 못한 후보 또는 국면 시작 시 미준공 셀과 이유. 창 방식에서 양쪽 창 모두 거래가 없는 셀은 후보에 들어오지 않는다.
- `missing_features_v1.csv`: 국면·방식·특성별 결측 수.
- `static_conflicts_v1.csv`: 같은 단지에서 값이 둘 이상인 919개 단지×열 조합(빈 값과 비어 있지 않은 값의 차이 포함). 값 충돌은 후속 강건성 검토 대상이다.
- `provenance_v1.json`: 입력 파일 해시·환경 버전·행 수 대사.
- `verification_v1.json`: 전체 표 구조 검사와 원거래 기반 240개 목표값 독립 재계산 결과.

학습 X는 `config/features.yaml`의 기본 특성 목록으로 **명시적으로 선택**해야 한다.
`z`, `z_start`, `z_end`, `tz`, 거래 수·기간 등 검증용 열과 식별자를 자동으로 학습 X에 포함하면 안 된다.

## 재현

```bash
python src/cells/build_cells.py
python tools/verify_cells.py
python -m pytest -q
python tools/verify_final.py
```

계산 규칙은 `config/cells.yaml`에 추가로 명시했다. 결과를 의도적으로 갱신했을 때만
`python tools/verify_final.py --update`를 실행하고 변경 이유를 기록한다.
다음 단계는 법정동 분할 고정과 모델 학습이다. 위 표본·제외 규칙을 유지한 상태에서 진행한다.
